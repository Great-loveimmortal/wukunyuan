# 项目背景
我正在使用 Python 开发一个名为“文章下载器（简易版）”的桌面软件。目标是爬取指定网站（基于人民网“习近平系列重要讲话数据库”的结构）的文章，并保存为 Word 文档（.docx）。此项目旨在学习并实践 AI 协同开发，最终需打包成无需 Python 环境的独立 exe 软件。

# 技术栈要求
- 语言：Python
- UI 框架：CustomTkinter (ctk)，要求极简白底风格。
- 爬虫技术：DrissionPage（用于浏览器伪装和绕过反爬） + requests (用于多线程下载详情页) + lxml (用于解析 HTML) + json (解析 API 接口)。
- 🌟 文档处理：使用 `python-docx` 库，将抓取到的文章内容生成排版好的 Word 文档。
- 并发要求：必须使用 `threading` 将爬虫逻辑与 UI 主线程隔离，防止界面卡死。如需多线程下载，使用 `concurrent.futures.ThreadPoolExecutor`。
- 🌟 打包工具：使用 `PyInstaller`。

# 架构规范（核心要求）
请将程序拆分为以下文件，保持高内聚低耦合：
1. `main.py`：UI 主程序。只负责界面绘制、按钮点击事件、弹窗提示。
2. `spider.py`：爬虫核心逻辑。包含搜索数据、下载文章、🌟 调用 Word 生成逻辑的代码。
3. `utils.py`：工具类（如路径校验、打开文件夹等）。

# 界面与功能需求 (UI Design)
- 整体布局：白底，顶部靠左显示标题“文章下载器（简易版）”。
- 上部区域（参数区）：
  - 搜索输入框（为空，占位符提示输入文字），右侧有“搜索”按钮。
  - 保存文件夹输入框（支持手动输入和展示选择结果），右侧有“请选择”按钮。
- 下部区域（控制与日志区）：
  - 左侧：大面积的日志输出框（初始为空），需要实时更新。
  - 右侧：垂直排列的操作按钮：“打开文件夹”、“开始下载”、“停止下载”、“退出”、“设置”。
- 设置弹窗：
  - 包含一个单选框（RadioButton）：“启用多线程”（默认选中） / “不使用”。
  - 右下角有“取消”和“应用”按钮，应用后更新多线程状态变量。

# 交互与业务逻辑要求
1. **搜索逻辑**：点击“搜索”后，需要在日志区打印“注：此结果仅为精确搜索”，并解析接口返回的 JSON 中的 `total` 字段，打印“共搜索到(x)篇文章”。
2. **文件夹选择**：选择或输入文件夹后，必须调用工具函数校验路径。如果合法，打印提示；如果不合法，清空输入框并提示重选。
3. **开始下载**：点击后，启动子线程执行 `spider.py`。日志区需要实时输出“开始下载”、“正在下载第(x)篇文章”等状态。
4. 🌟 **文件保存逻辑**：提取的文章内容（主标题、副标题、来源时间、正文段落），必须使用 `python-docx` 将其写入到 `.docx` 文件中。主标题、副标题应使用对应的 Heading 样式，正文按段落写入。
5. **停止下载**：绝对不能使用强行杀线程的方法。请使用全局标志位（如 `is_running`），爬虫循环中检测到标志为 False 时，安全退出循环，并在日志区大字号打印“已停止下载”。
6. **退出程序**：强制停止爬虫子线程，并销毁 UI 窗口。
7. **打开文件夹**：使用系统命令打开用户选择的文件夹路径。

# 🌟 打包与发布规范
- 最终需要使用 `PyInstaller` 将程序打包成单个独立的 `exe` 文件（使用 `--noconfirm --onefile --windowed` 参数）。
- 打包时需注意 CustomTkinter 的隐藏依赖导入（如 `PIL._tkinter_finder`）。
- 确保 DrissionPage 的底层依赖在打包后能正常工作。

# 重点避坑提示（写给 AI 的话）
- UI 线程阻塞：严禁在 UI 按钮的事件函数中直接写 `time.sleep` 或 `requests.get`，必须使用 `threading.Thread`。
- 通信机制：由于爬虫在子线程，更新日志区请使用 `queue.Queue`。子线程将日志字符串放入队列，主线程通过 `root.after(100, check_queue)` 循环读取并更新 Text 控件。
- 🌟 文件名与路径校验：保存 Word 时，保存路径拼接必须使用 `os.path.join`，文件名（如主标题）必须使用正则 `re.sub(r'[\\/:*?"<>|]', '_', title)` 进行非法字符清洗，防止操作系统报错。
- 爬虫异常处理：网页结构可能变异，解析 HTML 必须使用 `try-except` 包裹，解析失败时打印错误并 `continue` 跳过该文章，绝不能让整个程序崩溃。
